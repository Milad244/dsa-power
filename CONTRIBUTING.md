# Contributing

Contributions are welcome!  

You can add new functions to the existing data structures (queue, stack, DLL, str, etc.). Please follow the same `.c` and `.h` format as the current files, and add corresponding unit tests in the test files.  

## Instructions

1. **Fork the repository** and create a new branch for your changes.  
2. **Add your function** to the appropriate `.c` and `.h` files, following the existing style and formatting.  
3. **Write unit tests** in the test files to verify your function works correctly.  
4. **Run existing tests** to ensure nothing else breaks.  
5. **Commit your changes** with a clear message describing what you added.  
6. **Submit a pull request** for review.  

Thank you for helping improve this project!
